Google sign-in (OAuth client)

{% if client.present %}✓Client saved {{ client.client_id }}{% else %}–Not set up{% endif %}

One-time setup. This is the hub's own “app” in Google Cloud. It isn't a channel or an account: every channel and every Google account signs in through it.

{% if client.use_instead %}
This client is registered for {{ client.use_instead }}. Open the hub at that address to sign in, or add {{ client.redirect_uri }} to the client's Authorized redirect URIs in Google Cloud.
{% elif client.present and not client.redirect_ok %}
This client doesn't list the hub's redirect URI. In Google Cloud → Credentials → your OAuth client, add {{ client.redirect_uri }} under Authorized redirect URIs, then save the client here again.
{% endif %} {% if client.error %}
{{ client.error }}
{% endif %}

Stored only on this PC, in output/hub/secrets/, which git ignores. Channels already connected keep working after you switch clients.

  1. Open Google Cloud and create a project, e.g. “Content Hub”.
  2. In APIs & Services → Library, enable YouTube Data API v3 and YouTube Analytics API.
  3. In OAuth consent screen: choose External, and add every Google account that owns a channel under Test users.
  4. In Credentials → Create credentials → OAuth client ID: type Web application, with this Authorized redirect URI:
    {{ client.redirect_uri }}
  5. Paste the Client ID and secret on the left.

While the app is in testing mode Google expires sign-ins after 7 days, so channels need Reconnect weekly. Publishing the app (and passing YouTube's API audit) removes that limit and lets uploads go public.
