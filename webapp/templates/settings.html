How to get the client file (one time)

  1. Open Google Cloud and create a project, e.g. “Content Hub”.
  2. In APIs & Services → Library, enable YouTube Data API v3 and YouTube Analytics API.
  3. In OAuth consent screen: choose External, fill in the app name and your email, and add your own Google account under Test users.
  4. In Credentials → Create credentials → OAuth client ID: type Web application, and add this exact Authorized redirect URI:
    {{ client.redirect_uri }}
  5. Download the JSON and upload it on the left.

While the app is in testing mode Google expires sign-ins after 7 days, so channels need reconnecting weekly. Publishing the app (and passing YouTube's API audit) removes that limit and lets uploads go public.
